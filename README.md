# Customer Segmentation using K-Means and Agglomerative Clustering

## Project Overview
This project focuses on segmenting customers into different groups based on their income, spending behaviour, age, and family-related characteristics.
Machine Learning clustering techniques are used to identify different customer groups and understand their characteristics.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Steps Performed
1. Data Loading
2. Data Cleaning
3. Missing Value Handling
4. Feature Engineering
5. Data Preprocessing
6. Feature Encoding
7. Feature Scaling
8. PCA Dimensionality Reduction
9. K-Means Clustering
10. Agglomerative Clustering
11. Silhouette Score Evaluation
12. Customer Profiling
13. Cluster Visualization

## Clustering Algorithms
- K-Means Clustering
- Agglomerative Clustering

## Results
K-Means clustering was used to create 4 customer segments.

- K-Means Silhouette Score: **0.4362**
- Agglomerative Clustering Silhouette Score: **0.3634**

The clusters represent different customer profiles based on their income, spending behaviour, age, and family-related characteristics.

## Conclusion
Customer segmentation can help businesses understand different types of customers and support targeted marketing strategies.
